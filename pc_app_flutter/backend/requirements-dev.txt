# core/utils.py imports `requests`, which ships no py.typed marker. mypy reports
# that as `import-untyped`, and `ignore_missing_imports = true` does NOT suppress
# it — that setting only covers modules mypy cannot find at all, not modules that
# are installed without stubs. Without this pin the mypy CI step fails on a clean
# install while passing in a venv where requests happens to be absent.
# Version tracks requests==2.32.x from requirements.txt.

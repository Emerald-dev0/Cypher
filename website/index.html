FAQ

Real questions.
Straight answers.

Does it actually work without internet?

Yes, completely. Every byte travels directly between your phone and PC over your local WiFi. Internet is never required for any feature.

How fast are transfers really?

On a 5GHz hotspot you can expect 20–50 MB/s. A 1GB file transfers in about 30 seconds. Much faster than Bluetooth, comparable to USB.

Can anyone else access my files?

Only devices you explicitly pair using the 6-digit code. Random devices on the same network cannot connect without the code.

What file types work?

All of them. CYPHER transfers raw bytes — documents, 4K videos, executables, zip archives. No restrictions on type or size.

Does the PC need to stay on?

Yes, your PC needs to be on and running the CYPHER app. You can remotely sleep or shut it down via the phone when you're done.

Is CYPHER really free?

Yes. No premium tier, no subscription, no feature gates. Everything is free forever. It's open source on GitHub.
